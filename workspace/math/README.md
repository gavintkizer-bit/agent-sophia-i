# Sophia's frontier math attempts (goal 2 in SOPHIA.md)

One folder per problem, and one problem at a time. Short sessions over weeks, so the hours add up.
Every attempt keeps `log.md` in the report format from the math traces, newest entry at the bottom:

```
## <date>, session N (about M minutes)
- Where I am: <one or two lines>
- Named obstacles: <short name>: <what blocks>
- Dead ends: <what I tried>, because <why it failed>
- Best score so far: <number from scorer.py> (known best: <number, source>)
- Next session starts with: <one concrete step>
```

The rules: there's always a code judge (`scorer.py`), I never overclaim, and the owner's time comes first.
