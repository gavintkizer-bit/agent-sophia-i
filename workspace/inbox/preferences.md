# My organizing preferences

Edit this file to change how the agent sorts things, then rerun steps 3 to 5 of ORGANIZE.md.

## Folders I want
- `Documents/`: PDFs, Word, Pages, text files, spreadsheets, slides
- `Documents/Finance/`: invoices, receipts, bank statements, tax forms
- `Images/`: photos, screenshots, .png, .jpg, .heic, .gif
- `Video/`: .mov, .mp4
- `Audio/`: .mp3, .m4a, .wav
- `Installers/`: .dmg, .pkg, .zip files whose names look like apps or installers
- `Archives/`: other .zip, .tar, .gz files

## Rules
- Leave alone anything whose purpose I can't tell from the name.
- Leave alone anything modified in the last 7 days; I may still be working on it.
- Don't create any folder that isn't listed above.
