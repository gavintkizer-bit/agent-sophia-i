# My organizing preferences

Edit this file to change how Sophia sorts things, then run `python sophia.py` again.

## Folders I want
- `Documents/`: PDFs, Word, Pages, text files, spreadsheets, slides, ebooks
- `Documents/Finance/`: invoices, receipts, bank statements, tax forms
- `Images/`: photos, screenshots, .png, .jpg, .heic, .gif
- `Video/`: .mov, .mp4, .mkv
- `Installers/`: .zip files whose names look like apps or installers
- `Archives/`: other .zip, .tar, .gz files
- `Web Pages/`: saved .html pages and their files
- `_Sophia To Delete/`: things that look deletable (duplicates, old installers, installed
  Ableton packs). Sophia only MOVES them here; I check the folder and drag it to the Trash myself.

## Rules
- NEVER move audio or Ableton files (.wav, .mp3, .aif, .asd, .als, ...): my Ableton projects
  find samples by where they are. (This is also enforced in code.)
- Leave alone anything whose purpose I can't tell from the name.
- Leave alone anything modified in the last 7 days; I may still be working on it.
- Don't create any folder that isn't listed above.
