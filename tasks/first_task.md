# Task: Turn my messy notes into an organized plan

Read every file in the `notes/` folder.

Then create a file named `organized_plan.md` (in the workspace root, not inside notes/) containing:

1. **Goal**: one sentence stating what I'm trying to achieve.
2. **Constraints**: my limitations, as a short list.
3. **Plan**: the three paths (A, B, C) as sections. For each: what it is, what it costs or requires, and the next 1-3 concrete actions.
4. **Open questions**: anything in the notes that is unclear or contradictory.
5. **Recommended next step**: one sentence.

Keep it under 400 words. Only use information found in the notes.
