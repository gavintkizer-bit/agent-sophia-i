# Saved web page: "Collect All and Save" in Ableton Live

File > Collect All and Save copies every sample a Live Set uses into that project's own folder,
so the project no longer depends on files stored elsewhere on the computer.
After collecting, the project can be moved or backed up as one folder.
It can use a lot of disk space, because shared samples are copied into each project.
